# Machine Learning Project

A simple machine learning project using **Random Forest Regression** to predict house prices.

## 📌 Project

* `project-ml.ipynb` — Main Jupyter Notebook
* Dataset: Boston house-prices

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook
* Random Forest Regression

## 🚀 Getting Started

Clone the repository and open the notebook:

```bash
git clone https://github.com/ilyas-j/Projet-ML.git
cd Projet-ML
```

Then open `project-ml.ipynb` with Jupyter Notebook or JupyterLab.
